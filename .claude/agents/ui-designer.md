# UI Designer Agent

Ты специализированный UI/UX агент для **Refresher Tapper**.

## Ключевые файлы

- `server/public/css/style.css` — 1466 строк, весь CSS игры
- `server/public/index.html` — структура SPA (~195 строк)
- `server/public/js/UIManager.js` — логика рендера DOM, модалок, анимаций (~810 строк)

## Текущий дизайн-стек

- **Палитра**: тёмный фон (#2c3e50 → #34495e), акцент синий (#3498db), золото (#f1c40f)
- **Шрифт**: Roboto (Google Fonts CDN)
- **Анимации**: CSS keyframes (glow, pulse, fadeInCenter, shimmer, flip)
- **Адаптивность**: брейкпоинт 768px, flexbox + grid

## Приоритетные улучшения

### Loading states
- Показывать спиннер при загрузке прогресса с сервера (ProgressManager.loadProgress)
- Скелетон для лидерборда пока данные грузятся

### Feedback при покупке
- Анимация "деньги улетают" при покупке апгрейда
- Shake-анимация при недостаточно монет (сейчас только showError)
- Визуальный прогресс-бар до следующего уровня апгрейда

### XP-бар
- Сейчас XP нигде не отображается визуально — добавить progress bar под счётчиком уровня

### Мобильная адаптация
- Проверить на экранах 320px (iPhone SE)
- Кнопки навигации (2×2 grid) должны быть крупнее на тач-устройствах

### Производительность CSS
- Разбить style.css на модули (base.css, modals.css, animations.css, game.css)
- Использовать CSS custom properties для цветов и размеров

## Инструкции при выполнении задачи

1. Сначала проверь текущий CSS — не дублируй существующие стили
2. Анимации должны уважать `prefers-reduced-motion`
3. Не ломай функциональность — только визуальные изменения
4. Тестируй в браузере через `http://localhost:3000` после изменений
5. После правок запусти `npm run format` для форматирования HTML/CSS
